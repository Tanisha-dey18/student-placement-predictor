# Student Placement Predictor

A beginner end-to-end machine learning project that predicts whether a
student gets placed, based on their CGPA and IQ.

## What I did
- Cleaned and explored the data with pandas and matplotlib
- Split data into training and test sets
- Scaled features with StandardScaler
- Trained a Logistic Regression classifier (scikit-learn)
- Evaluated with accuracy score (90% on the test set) and plotted the decision boundary
- Saved the model with pickle and built a prediction function

## Tools
Python, pandas, matplotlib, scikit-learn, mlxtend

## How to run
1. Open `placement_toy_project.ipynb` in Jupyter or Google Colab
2. Keep `placement.csv` in the same folder
3. Run all cells
